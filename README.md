### 1. HMO Claims Analytics

End-to-end analysis of simulated healthcare claims data to examine healthcare utilization, claim spending, provider activity, member characteristics, claim outcomes, processing performance, and high-cost claims.

**Tools:** Python | SQL | SQLite | Power BI | Pandas | Matplotlib

**Focus:** Data validation, data cleaning, exploratory data analysis, business metrics, SQL querying, healthcare claims analysis, high-cost claim analysis, and interactive dashboard development.

**Key Outputs:**

- 50,000 simulated claims
- 20,000 simulated members
- Python data analysis
- SQL business analysis
- Power BI dashboard
- Claims trend analysis
- Service type analysis
- Provider analysis
- High-cost claims analysis
